1. CRITICAL BUGS FIXED THIS PHASE
================================================================================

BUG P4-1: Texture Alias Parsing (SEVERITY: CRITICAL)
  Symptom: External textures (TubeDiffuseImage, BackgroundImage, etc.) never bound
  Root cause: Preset uses "alias8 = TubeDiffuseImage" but parser looked for
             "alias_texture8". Texture aliases use flat indices starting at
             numShaders, not "alias_textureN" format.
  Fix: Added detection of "aliasN" where N >= numShaders as texture aliases,
       mapped to texture index via (i - numShaders).
  File: main.cpp ~line 1169, test_translator.cpp ~line 166
  Impact: ALL external textures were previously unresolved. Now correctly bound.

BUG P4-2: UBO Members Not Emitted as Uniforms (SEVERITY: CRITICAL)
  Symptom: 700+ HSM parameters (HSM_SINDEN_BORDER_ON, HSM_CACHE_GRAPHICS_ON,
           etc.) referenced in shader code but never declared as uniforms.
  Root cause: Translator extracted UBO block from globals.inc into uboMembers
             string but never emitted them in the GLSL output. The "global.X"
             prefix was stripped from code, leaving undeclared variables.
  Fix: Emit UBO members as individual "uniform" declarations in GLSL output,
       skipping already-declared names (SourceSize, OutputSize, etc.).
  File: main.cpp ~line 2750, test_translator.cpp ~line 544
  Impact: ALL Mega Bezel shaders would fail to compile. Now properly declared.

BUG P4-3: Self-Referencing Local Variables (SEVERITY: HIGH)
  Symptom: "float HSM_SINDEN_BORDER_ON = HSM_SINDEN_BORDER_ON;" compile error
  Root cause: params-0-screen-scale.inc creates local variables like
             "float X = global.X;". After global.X stripping, becomes
             self-referencing. Combined with UBO emission of same-named
             uniform, creates redeclaration + self-init error.
  Fix: After emitting UBO uniforms, scan preamble helpers and remove
       self-referencing "float X = X..." lines (uniform already provides value).
  File: main.cpp ~line 2783, test_translator.cpp ~line 580
  Impact: Shader compilation failure. Now properly handled.

5. KNOWN VISUAL DIFFERENCES VS RETROARCH
================================================================================

DIFF-1: Missing Mega Bezel passes (by design)
  Our preset omits: DerezedPass, DeditherPass, LinearizePass,
  ColorCorrectPass, CRTPass, ReflectionPass. These are referenced as
  samplers in combine-passes.inc but get black placeholders.
  Impact: No dedithering, no linearization, no reflection.
  Mitigation: These are optional in the Mega Bezel pipeline.

DIFF-2: CRT simulation uses Lottes shader
  RetroArch Mega Bezel uses its own CRT pass (CRTPass). Our preset uses
  the Lottes CRT (bloompass + scanpass) which has different curvature,
  mask, and scanline characteristics.
  Impact: Different CRT visual appearance (curvature, mask pattern).
  Mitigation: Lottes is a well-known CRT emulation, visually acceptable.

DIFF-3: Feedback textures start black
  On first frame, feedback textures are initialized with black pixels.
  RetroArch Mega Bezel may have persistent cache. Our feedback starts
  empty and accumulates over frames.
  Impact: First few frames may look different (no cached geometry).
  Mitigation: Cache fills within 2-3 frames.

DIFF-4: HSM parameters use defaults
  All HSM parameters use their #pragma parameter default values.
  No UI controls to adjust them at runtime (yet).
  Impact: Bezel position/size is fixed at default.
  Mitigation: Parameters are exposed as uniforms; UI can be added.
